# BG Studio AI

حذف پس‌زمینه عکس و ویدیو کاملاً در مرورگر کاربر. بدون سرور، بدون API، بدون هزینه.

## ساختار
```
bg-studio-ai/
├── public/
│   ├── index.html          # همه صفحات (خانه، عکس، ویدیو، راهنما، درباره ما) با مسیریابی #hash
│   ├── css/styles.css
│   ├── js/model-config.js  # آدرس مدل و کتابخانه‌ها (همین‌جا را بررسی کنید)
│   ├── js/model-loader.js  # دانلود و کش مدل، پیش‌پردازش، ترکیب ماسک
│   ├── js/worker.js        # اجرای ONNX Runtime در Web Worker (WebGPU یا WASM)
│   ├── js/image.js         # منطق صفحه عکس
│   └── js/video.js         # منطق صفحه ویدیو (FFmpeg.wasm + فریم‌به‌فریم)
```

## اجرا
فقط یک سرور استاتیک لازم است (روی GitHub Pages یا Cloudflare Pages مستقیم منتشر کنید). برای تست محلی:
`cd public && python3 -m http.server 8080` و سپس http://localhost:8080 را باز کنید.

## نکات
- اولین بار مدل (حدود ده‌ها مگابایت) دانلود و در Cache Storage ذخیره می‌شود.
- ویدیو حداکثر ۳۰ ثانیه، و خروجی MP4 با پس‌زمینه رنگی است.
- خروجی شفاف فقط برای عکس است.

## محدودیت‌های شناخته‌شده
- مدل از ریپوی onnx-community/BiRefNet-ONNX (فایل onnx/model.onnx، حدود ۹۷۳ مگابایت) گرفته شده. این حجم برای موبایل سنگین است؛ نسخه fp16 (حدود ۴۹۰ مگابایت) یا مدل ۵۱۲×۵۱۲ گزینه‌های سبک‌تر هستند ولی هنوز تست نشده‌اند.
- نسخه کتابخانه‌ها (ONNX Runtime Web، FFmpeg.wasm) در سندباکس تست نشده‌اند.
- ماسک ۱۰۲۴×۱۰۲۴ است، پس لبه‌های خیلی ریز (مو) ممکن است کمی نرم شوند. Matting دقیق‌تر نیاز به مدل جدا دارد.
- ویدیو فریم‌ها را در حافظه FFmpeg نگه می‌دارد؛ ویدیوهای بلند روی دستگاه‌های ضعیف ممکن است خطای حافظه بدهند.
- ویدیو فعلاً پس‌زمینه شفاف ندارد.
- انیمیشن‌ها و Glassmorphism با مرورگرهای قدیمی ممکن است متفاوت دیده شوند.
